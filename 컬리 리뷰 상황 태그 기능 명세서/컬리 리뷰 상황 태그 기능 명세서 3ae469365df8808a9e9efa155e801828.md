# 컬리 리뷰 상황 태그 기능 명세서

### 핵심 기능 정의

<aside>
🎯

**기능명**: 리뷰 상황 태그 (작성 시 선택 입력 + 조회 시 배지 노출)

**기능 한 줄 설명**: 리뷰 작성자가 자신의 이용 상황(인원·목적·동반자·맛)을 태그로 남기면, 조회자는 리뷰 카드에서 이 태그를 배지로 바로 확인할 수 있다.

**이 기능을 핵심으로 선정한 이유**: [PRD 내 4.2 근본 원인 1(입력 구조의 부재)](https://app.notion.com/p/PRD-3ae469365df8804f93ace4f7a0b666b6?pvs=21)을 직접 해소하는 최소 단위 기능이며, RICE 우선순위 1위(8.1점)로 별도 인프라 없이 기존 리뷰 작성·조회 화면에 필드·배지만 추가해 구현 가능하다.

</aside>

### User Flow

![리뷰 개인화-페이지-1.drawio (1).png](%EC%BB%AC%EB%A6%AC%20%EB%A6%AC%EB%B7%B0%20%EC%83%81%ED%99%A9%20%ED%83%9C%EA%B7%B8%20%EA%B8%B0%EB%8A%A5%20%EB%AA%85%EC%84%B8%EC%84%9C/%E1%84%85%E1%85%B5%E1%84%87%E1%85%B2_%E1%84%80%E1%85%A2%E1%84%8B%E1%85%B5%E1%86%AB%E1%84%92%E1%85%AA-%E1%84%91%E1%85%A6%E1%84%8B%E1%85%B5%E1%84%8C%E1%85%B5-1.drawio_(1).png)

- **핵심 기능 유저플로우 상세 설명**
1. 작성자가 리뷰 작성 화면 내에서 스크롤하면 상황 태그 선택 섹션이 노출된다
2. 인원수·목적·동반자(단일 선택)와 맛(다중 선택) 중 원하는 항목만 골라 선택한다 (전체 스킵 가능)
3. 사진 및 텍스트 작성 후 후기 등록 버튼 클릭 시 선택한 태그가 리뷰 데이터와 함께 저장된다
4. 조회자가 리뷰 목록에 진입하면 각 카드 상단에 작성자가 남긴 태그가 배지로 노출된다
5. 노출 태그가 4개를 초과하면 앞 4개만 보이고 "+N 더보기"로 축약되며, 탭하면 전체 태그가 5개 단위로 줄바꿈되어 펼쳐진다

### 8_예외 처리

| 상황 | 처리 방식 |
| --- | --- |
| 빈 화면 (태그 미선택) | 작성자가 상황 태그를 하나도 선택하지 않고 등록한 리뷰는 카드 상단 배지 영역 자체를 노출하지 않는다 |
| 로딩 상태 | 태그 선택은 클라이언트 로컬 상태라 별도 로딩이 없음. 리뷰 목록 진입 시 태그 데이터는 리뷰 본문과 함께 한 번에 로드되며, 로딩 중에는 카드 전체가 스켈레톤으로 표시된다 (기존과 동일) |
| 에러 상태 (네트워크 오류 등) | 리뷰 본문과 태그는 하나의 등록 요청으로 묶어 처리하며, 리뷰 등록 API 호출이 실패하면 선택한 태그값은 유지한 채 에러 토스트를 노출하고, 재시도할 수 있게 한다 (기존과 동일) |
| 기존 리뷰 (기능 출시 이전 작성) 조회/수정 시 | 본 기능 출시 이전에 작성된 기존 리뷰(태그 정보 없음)는 "태그 미선택" 상태와 동일하게 처리한다.  |
