## 1. 목표

### **개선 목표**

<aside>
🎯

**마켓컬리의 리뷰 탐색 저니를 개선해, 사용자가 "이 상품이 사용자 개개인의 상황(인원·목적·동반자·맛)에 맞을지"를 컬리 안에서 빠르게 판단하게 함으로써 탐색 이탈과 구매 실패를 줄이고, 재구매를 끌어올린다.**

<aside>
💡

</aside>

- 기존 리뷰 정렬은 추천순·최신순을 통해 다수에게 대표적인 리뷰를 제공하지만, 개별 사용자에게 적합한 리뷰를 보장하지는 않는다.
- 작성자·조회자의 상황을 데이터로 구조화해 "내 기준의 리뷰"를 스스로 골라 해석하도록 돕는다.

### 2.3 개선 서비스 선택 : 마켓컬리

#### 1) 상황 정보가 식품 구매 판단에 직접적인 영향을 준다

간편식과 밀키트는 제품 설명만으로 다음 정보를 정확하게 판단하기 어렵다.

- 실제로 몇 명이 먹기에 적절한 양인지
- 어떤 상황이나 목적을 위해 구매하는 것이 적합한지
- 함께 먹는 사람이 성인인지 아동인지
- 상품이 나의 입맛과 얼마나 잘 맞는지

따라서 구매자의 이용 상황이 상품 만족도를 크게 좌우한다.

예시)

| 리뷰 표현 | 1인 가구의 해석 | 다인 가구의 해석 |
| --- | --- | --- |
| “양이 정말 많아요” | 남기거나 폐기할 가능성 | 가성비가 좋음 |
| “많이 맵지 않아요” | 맛이 약하거나 싱거울 수 있음 | 아이와 함께 먹기 적절함 |
| “조리하기 간편해요” | 짧은 시간 안에 조리 가능 | 작성자의 간편함 기준을 알 수 없음 |

### **3.2 핵심 타겟 정의**

<aside>
🙋‍♀️

**30대 여성 · 직장인(소득 있음, 바쁨) · 2인 가구**

**라이프스타일** : 건강·웰니스에 관심 있으나 퇴근 후 손이 많이 가는 요리는 지양

**사용 패턴** : 주 1~2회 주문, 구매 전 리뷰 10개 이상 확인, 부족하면 유튜브로 교차 검증

**페인포인트** : 가구 형태(2인분의 양)·취향(맛 강도) 정보가 리뷰에 반영되어 있지 않음

</aside>

> 주말에 냉장고를 살피며 컬리 앱을 켜고 상품 탐색을 시작합니다. 마음에 드는 식재료/간편식을 찾아 구매 확신을 얻기 위해 리뷰를 확인하는 순간부터 문제가 시작됩니다. 

리뷰 정렬은 추천순·최신순뿐이라, 위에서부터 읽어 내려가며 "이 사람은 몇 명이서 먹은 걸까", “자극적이지 않으면서도 감칠맛이 있는가” 등을 리뷰 텍스트를 통해 추측해야 합니다. 

10개 넘게 읽어도 확신이 안 서면 컬리를 벗어나 유튜브에서 관련 영상을 몇 개 더 찾아보고 나서야 인원수나 맵기 같은 궁금증이 어느 정도 해소되고, "이 정도면 괜찮겠다" 싶어 구매를 결정합니다. 며칠 뒤 상품이 도착하면 포장을 뜯으면서 오래 고민한 보람이 있기를 바랍니다.
> 
> 
> 그런데 막상 조리해서 먹어보면 리뷰만으로는 알 수 없었던 어긋남이 드러납니다. 생각보다 양이 애매하거나, 예상보다 자극적인 맛이거나—결국 "이건 내 상황엔 안 맞았다"는 생각을 합니다.
> 
> 결과 처리 단계에서는 반품하기도 애매하고 그냥 두기도 아까워, 처음부터 다시 대체 상품을 찾아 나섭니다. 리뷰를 뒤지고 유튜브까지 확인했던 과정을 한 번 더 반복해야 한다는 생각에 탐색 피로가 크게 쌓입니다.
> 
> 이런 경험이 쌓이며 "컬리 리뷰만으로는 내 상황에 맞는지 알 수 없다"는 인식이 굳어지고, 이후에는 리뷰를 봐도 선뜻 구매를 쉽사리 결정하지 못하거나, 리뷰보다 외부 채널을 먼저 확인하는 습관이 자리 잡습니다.

## 4. 문제 정의

### 4.1 문제 현상

> 컬리의 메인 사용자군(바쁜 직장인, 3040 연령대, 좋은 품질과 맛을 주요 구매 요인으로 판단)은 
구매 확신의 근거를 리뷰에 의존하지만, 
리뷰를 읽어도 다수에게 대표적인 리뷰는 확인할 수 있으나
"이게 내 경우에 해당되는 이야기인가"를 판단할 수 없어 확신에 도달하지 못한다.
> 

### 4.2 근본 원인

리뷰 작성자와 조회자의 상황 정보가 정형 데이터로 구조화되어 있지 않다. 
원인을 세 층으로 분해하면 다음과 같다.

#### **원인 1. 입력 구조의 부재**

> 리뷰 시스템이 "사진 + 자유 서술형 텍스트"로만 설계되어 있고, 
작성자의 상황(가구 인원, 함께 먹은 사람, 사용 상황)을 정형 값으로 저장 및 관리할 수 있는 입력란이 없어서 유용한 정보를 남겨도 텍스트 속에 묻힌다.
> 

#### **원인 2. 정렬 기준이 다수 의견에 편향**

> 추천순과 최신 등록순은 "대표 리뷰"를 뽑는 기준이지 "나에게 맞는 리뷰"를 뽑는 기준이 아니다. 
컬리에는 이 2개 정렬과 상품 옵션 필터만 존재한다.
> 

#### **원인 3. 조회자 측 조건 입력 경로도 없음**

> 조회자가 자기 상황을 시스템에 알릴 방법이 없으므로, 시스템은 개인화할 재료 자체를 갖지 못한다.
> 

### 4.3 핵심 문제 정의

<aside>
🎯

**건강과 음식 취향을 중요하게 생각하지만 요리할 시간이 부족한 2~3인 가구의 직장인 사용자는 컬리에서 간편식이나 식재료를 구매할 때, 해당 상품이 자신의 가구 형태와 입맛에 적합한지 리뷰를 통해 판단하려 한다.** 

**그러나 자신과 유사한 조건의 리뷰를 쉽게 찾기 어려워 충분한 구매 확신을 얻지 못하거나, 리뷰가 자신의 상황에도 적용되는지 정확히 판단하지 못한 채 구매할 수 있다.** 

**이 경우 기대와 실제 이용 경험의 불일치가 식품의 방치·폐기로 이어질 수 있으며, 

반복되는 구매 실패로 해당 상품이나 플랫폼의 재구매 의향이 낮아진다.

반복되는 구매 실패 경험으로 인해 리뷰 탐색 시간이 더욱 길어져서 장바구니 전환율이 낮아진다.**

</aside>

#### 리뷰 작성 및 조회 사용자 플로우 후보

### 핵심 지표

| 지표 | 정의·계산 방법 | 의미 |
| --- | --- | --- |
| **사용자 단위 30일 재구매율 1.3%p 증가** | 기능 노출 후 첫 구매를 완료한 사용자 중 30일 이내 컬리 식품 카테고리에서 다시 구매한 사용자 비율 | 가설의 최종 성공 여부 판단 |
- 지표 설정 근거
    
    ```
    [1단계] 문제가 재구매를 갉아먹는 경로의 크기 추정
      설문: "내 상황과 맞지 않는 리뷰가 많아 참고하기 어렵다"  24.3% (9/37)   [C]
      설문: 구매 실패 시 "해당 플랫폼 구매 빈도 하락"           27.0% (10/37)  [C]
    
      상황 미스매치 → 구매 빈도 하락 경로에 놓인 사용자 비중
      = 24.3% x 27.0% = 6.56%
    
    [2단계] MVP가 이 경로를 얼마나 차단하는가
      MVP 범위는 Must Have 2개(태그 입력 + 태그 표시)뿐이므로
      차단율을 15~25%로 가정, 그 중 중간값 채택
    
      15% 차단 → 6.56% x 0.15 = +0.98%p
      20% 차단 → 6.56% x 0.20 = +1.31%p   ← 채택
      25% 차단 → 6.56% x 0.25 = +1.64%p
    ```

#### 1차 검증 결과 시나리오

| 구분 | 지표 패턴 (트리거) | 해석 | 다음 액션 |
| --- | --- | --- | --- |
| 가드레일 (선행 게이트) | 가드레일 지표 중 하나라도 해당 | 태그 UX가 비용을 유발하고 있음 | 태그 섹션 경량화(기본 접힘, 그룹 축소, 렌더링 최적화) 후 재측정, 확장은 보류 |
| A. 성공·확장 | 재구매율 목표 달성 + 입력률 30% 이상 + 태그 있는 리뷰 도움돼요 클릭율 유의미하게 높음 | 가설 검증 성공 | 필터 추가부터 착수 후 유사순 정렬 검토 (Nice to Have 1순위) |
| B. 부분 성공·관망 | 보조지표(탐색시간↓·이탈률↓·클릭율↑)는 개선, 재구매율은 미달 | 리뷰 경험은 개선됐으나 구매~결제 단계에 다른 병목 | Nice to Have 보류, 후속 퍼널(리뷰를 보고 난 이후 단계들) 별도 진단 후 병목 파악 |
| C. 데이터 부족 | 표본 크기 미달 또는 태그 입력률 20% 미만  | 조회자에게 보여줄 태그 자체가 부족 | 입력 유인 강화(적립금, UI 위치 조정) + AI 자동 태그 추천(리뷰 텍스트에서 상황 정보 추출해 태그를 미리 제안) 도입 검토 |
| D. 노출 충분·무반응 | 입력률 30%↑, 조회자 지표(클릭율·이탈률)는 무변화 | 노출만으론 조회자 행동이 안 바뀜, 필터 필요성 시사 | 리뷰 목록 화면 내 상황 태그 매칭 리뷰만 골라보기 필터 추가 최우선 fast-track 진행 |
| E. 전면 무반응 | 태그 입력률 20% 미만 + 재구매율 목표 미달 | 작성자 및 조회자 모두에게 니즈 해소와 임팩트 없음 | 가설 재설계로 태그 항목(분류 체계, 선택지, 단위 등) 등 재검토 또는 확장 중단 |
