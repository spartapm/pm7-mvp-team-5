# pm7-mvp-team-5 — 컬리 리뷰 상황 태그 MVP

마켓컬리 리뷰에 **상황 태그**(인원·목적·동반자·맛)를 붙여, 조회자가 나와 비슷한 상황의 리뷰를 빠르게 파악할 수 있게 하는 **프로토타입**입니다.

- Next.js `14.2.35` + TypeScript + Tailwind
- Auth: Supabase (`@supabase/supabase-js`) + 로컬 폴백 (7일 세션)
- 더미데이터: `더미데이터_(1).xlsx` → `src/lib/seed-data.json`
- 클라이언트 상태(작성/수정/장바구니)는 `localStorage`에 유지

## 실행

```bash
npm install
npm run dev
```

브라우저: [http://localhost:3705](http://localhost:3705)

`.env.local`에 Supabase URL / publishable key가 필요합니다.

## 시연 플로우

### A. 로그인 / 회원가입

1. 홈 → 하단 **마이페이지** (비로그인 시 로그인 화면)
2. **회원가입** → 이메일·비밀번호·이름·만 14세 체크 → 가입하기
3. 또는 아이디/비밀번호 로그인 → 마이페이지 (`반가워요! {이름}님`)

### B. 작성자 — 상황 태그 입력

1. 마이페이지 → **후기** → **작성 가능 후기**
2. **후기 작성** → 상황 태그 선택(스킵 가능) → 텍스트 10자 이상 → **후기 등록**
3. 목록에서 해당 상품 제외 + 토스트 4초

### C. 작성자 — 수정·프리필

1. **작성한 후기** 탭 → **수정**
2. 기존 태그가 있으면 프리필 / 없으면 미선택 상태
3. 변경 후 **수정 완료** → 토스트

### D. 조회자 — 배지 노출 · 장바구니

1. 홈 → 상품 카드 → PDP → **후기** 탭
2. 카드 상단 상황 태그 배지 / `+N 더보기` (5개 단위 펼침)
3. **장바구니 담기** → 헤더 카운트(로그인 시) + 토스트
4. 장바구니 아이콘 → 장바구니 화면
   - 비로그인: CTA **로그인**
   - 로그인: **{금액} 주문하기** → 작성 가능 후기 추가 + 주문 완료 토스트

## MVP 범위 (기능명세서 1~54)

| 포함 | 제외(정적) |
| --- | --- |
| 로그인 / 회원가입 / 세션 7일 | 카테고리·검색 |
| 상황 태그 작성·수정·배지·더보기 | 주문내역·쿠폰·찜 |
| 장바구니 담기·수량·선택삭제·주문 | 조회자 필터·유사순 |
| 홈·마이페이지·PDP·후기 플로우 | 프로모션·혜택 영역 |
