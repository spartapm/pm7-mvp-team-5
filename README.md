# pm7-mvp-team-5 — 컬리 리뷰 상황 태그 MVP

마켓컬리 리뷰에 **상황 태그**(인원·목적·동반자·맛)를 붙여, 조회자가 나와 비슷한 상황의 리뷰를 빠르게 파악할 수 있게 하는 **프로토타입**입니다.

- Next.js `14.2.35` + TypeScript + Tailwind
- 더미데이터: `오르조_더미데이터.xlsx` → `src/lib/seed-data.json`
- 클라이언트 상태(작성/수정/장바구니)는 `localStorage`에 유지

## 실행

```bash
npm install
npm run dev
```

브라우저: [http://localhost:3705](http://localhost:3705)

## 시연 플로우

### A. 작성자 — 상황 태그 입력

1. **홈** → 하단 **마이페이지**
2. **후기** 아이콘 → **작성 가능 후기**
3. **후기 작성** → 상황 태그 선택(스킵 가능) → 텍스트 10자 이상 → **후기 등록**
4. 목록에서 해당 상품 제외 + 토스트 4초

### B. 작성자 — 수정·프리필

1. **작성한 후기** 탭 → **수정**
2. 기존 태그가 있으면 프리필 / 없으면 미선택 상태
3. 변경 후 **수정 완료** → 토스트

### C. 조회자 — 배지 노출

1. **홈** → 상품 카드 → PDP
2. **후기** 탭 (또는 `후기 N건 >`)
3. 카드 상단 상황 태그 배지 확인
4. 태그 5개 이상이면 `+N 더보기` → 탭 시 5개 단위 줄바꿈 펼침 (접기 없음)
5. **장바구니 담기** → 헤더 카운트 +1 + 토스트

## MVP 범위 (기능명세서 기준)

| 포함 | 제외 |
| --- | --- |
| 작성 시 상황 태그 선택 | 조회자 필터 |
| 목록 배지 노출 / +N 더보기 | 유사순 정렬 |
| 수정 프리필 | 마이페이지 상황 저장·온보딩 |
| 장바구니 카운트·토스트 | 카테고리/검색/주문내역 등 |
